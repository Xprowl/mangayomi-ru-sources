# Kodik proxy — бесплатный Cloudflare Worker

Kodik отдаёт видео через DDoS-Guard и с гео-ограничением: каждое обращение за сегментом
проверяется, поэтому плеер долго думает и иногда встаёт. Воркер забирает поток один раз со
стороны Cloudflare, кэширует и отдаёт приложению без проверок.

Стоимость: 0 ₽. Бесплатный тариф Workers — 100 000 запросов в сутки; сегментов в серии
~250 (по 6 секунд), плейлисты кэшируются на минуту, а сегменты — в edge-кэш Cloudflare.

## Что нужно

- аккаунт Cloudflare (бесплатный);
- Node.js 18+ для утилиты `wrangler`.

## Деплой (5 минут, один раз)

```bash
npm i -g wrangler
cd kodik-proxy-worker
wrangler login          # откроется браузер, войдите в Cloudflare
wrangler deploy
```

В конце `wrangler` напечатает адрес вида:

```
https://kodik-proxy.<ваш-сабдомен>.workers.dev
```

Если хотите короткое имя — впишите его в `wrangler.jsonc` (`"name": "animeon-video"`).

## Подключение в приложении

1. Mangayomi → AnimeOn → Настройки источника → **Прокси для видео**.
2. Вставьте адрес воркера: `https://kodik-proxy.<сабдомен>.workers.dev`.
3. Откройте серию — теперь плейлист и сегменты идут через воркер.

Поле пустое = видео напрямую с Kodik (как раньше).

## Как это работает

```
приложение ──► https://<worker>/?u=<kodik или cdn url> ──► Cloudflare edge ──► Kodik/CDN
```

- `*.m3u8` переписывается: каждая строка сегмента идёт через воркер, поэтому плеер
  больше не видит `solodcdn.com` и не спотыкается на `./720.mp4:hls:seg-1.ts`.
- Сегменты отдаются как есть (Range поддерживается), кэш на сутки.
- Разрешены только хосты Kodik и его CDN; чужие домены → 403.
- Если Kodik ответил ошибкой — воркер отдаёт её код и `{"error": ...}`.

## Ограничения

- Cloudflare Workers Free: 100 000 запросов/сутки. Серия с 250 сегментами = 250 запросов
  (сегменты кэшируются на сутки, так что повторный просмотр почти ничего не тратит).
- Если упрётесь в лимит — поднимите второй воркер и переключите адрес в настройках.
